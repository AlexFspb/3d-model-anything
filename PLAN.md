# Бесплатная установка 3D Model Anything на личный iPhone

## Исходная цель и границы

Собрать приложение в облаке, бесплатно установить на личный iPhone 16 Pro через Windows, проверить LiDAR-сканирование, экспорт комнаты и повторную подпись без потери данных. Код и документы ведём в публичном форке AlexFspb/3d-model-anything, без локального клонирования. GitHub Actions может делать checkout в своём временном macOS runner. Используем бесплатный Apple Account и стандартные бесплатные Actions. Восстановление Three.js-сцены и SideStore отложены. Пользователь выбрал первую итерацию: приложение и пробный скан.

## Принятые решения

- Upstream: wesbos/3d-model-anything, проверенный исходный commit 31b2dc9da3fb541e501f2f0936e55b32afb70ee8.
- Runner xcode-27, Xcode 27.0, XcodeGen; Release для физического iPhone arm64, сборка без подписи.
- Постоянный bundle ID: io.github.alexfspb.housecapture. При повторной подписи сохраняем тот же Apple Account и фактический установленный ID; приложение не удаляем.
- IPA, SHA256SUMS и build-info.json сохраняются в артефакте Actions на 30 дней. Пароли и сертификаты для CI не нужны.
- GitHub Actions закреплены по SHA; фактические версии XcodeGen и образа runner записываются в build-info.json. Бинарная идентичность будущих сборок не обещается.
- Установка через iloader Stable. Оплата, App Store/TestFlight, смена способа установки и обновление iOS не входят в текущую работу.
- Публичные API и house-capture/5 сохраняем; исходники меняем только для устранения обнаруженных ошибок сборки или запуска.
- Пользователь разрешил управление браузером для GitHub-настройки. Доступ к экрану других приложений и iPhone отдельно не разрешён; учётные данные вводит пользователь.
- Пароли, сертификаты, pairing-файлы, идентификаторы устройства и личные сканы не помещаем в публичный форк или CI.

## Этапы реализации

1. Создать форк только main и сохранить AGENTS.md и PLAN.md до настройки сборки.
2. Добавить .github/workflows/build-ios-ipa.yml: ручной запуск и запуск при изменениях приложения/workflow в main, без iOS-сборки на изменения одних документов. Отключить автоматическую публикацию сайта.
3. Сгенерировать Xcode-проект, собрать unsigned Release arm64 для устройства. Проверить Info.plist, bundle ID и платформу iOS. Упаковать Payload/HouseCapture.app в IPA, проверить ZIP, контрольную сумму и метаданные.
4. Проверить журнал Actions, исправить выявленные ошибки и сохранить ссылки на успешный запуск и commit. Успех CI не означает успех на телефоне.
5. Подготовить iloader и компоненты Apple на Windows. Пользователь подключает iPhone, вводит Apple ID, подтверждает доверие и включает Developer Mode.
6. Установить IPA, проверить запуск, разрешение камеры, короткий скан, сохранение комнаты и её повторное открытие.
7. Экспортировать комнату в ZIP через «Файлы» и передать на Windows доступным пользователю способом. Проверить архив, сохраняя его приватным.
8. Повторно подписать ту же сборку тем же Apple Account, установить поверх, проверить сохранность комнаты и записать фактическую процедуру.

## Продление подписи

Бесплатная подпись действует 7 дней. До истечения срока подключить iPhone к Windows, открыть iloader, использовать тот же Apple Account, IPA и установленный bundle ID, повторно подписать и установить поверх. Приложение предварительно не удалять. Сначала сохранить резервную копию тестового экспорта. Точные кнопки и сохранение данных проверим на устройстве; автоматическое продление в iloader не заявляется.
